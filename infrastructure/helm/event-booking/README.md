# event-booking Helm Chart

This chart deploys the assessment stack into Kubernetes or Minikube with a single Helm release.

## Included components

- `user-service` on port `3000`
- `event-service` on port `3001`
- `booking-service` on port `3002`
- `notification-service` on port `3003`
- `event-db` PostgreSQL
- `booking-db` PostgreSQL
- `redis`
- `kafka` in KRaft mode

## Values files

- `values.yaml` contains the default chart values.
- `values-minikube.yaml` overrides application images to local Minikube tags and uses lightweight resource settings.

## Minikube images

The Minikube workflow builds the four application images into the Minikube Docker daemon, using these tags:

- `event-booking/user-service:local`
- `event-booking/event-service:local`
- `event-booking/booking-service:local`
- `event-booking/notification-service:local`

`values-minikube.yaml` sets `imagePullPolicy: Never` for those images so Kubernetes does not try to pull them from a registry.

## Install

```bash
helm upgrade --install event-booking \
  infrastructure/helm/event-booking \
  -f infrastructure/helm/event-booking/values-minikube.yaml \
  --namespace event-booking \
  --create-namespace
```

## Inspect

```bash
helm list -n event-booking
kubectl get pods -n event-booking
kubectl get svc -n event-booking
kubectl get statefulsets -n event-booking
```

## Uninstall

```bash
helm uninstall event-booking -n event-booking
```

## Override examples

```bash
helm upgrade --install event-booking infrastructure/helm/event-booking \
  -f infrastructure/helm/event-booking/values-minikube.yaml \
  --set global.logLevel=debug \
  --set eventService.cacheTtlSeconds=300
```

## Notes

- User Service currently uses SQLite. The chart keeps that behavior and mounts persistent storage for the database file instead of creating a fake Postgres database.
- Database credentials and demo URLs are local-only placeholders for the assessment.
- Redis and Kafka are internal ClusterIP services. Application pods reach them through Kubernetes DNS names generated by this chart.
