# event-booking Helm Chart

This chart deploys the current event-booking microservices stack into Kubernetes or Minikube as a single Helm release.

## What it installs

- `user-service` on port `3000`
- `event-service` on port `3001`
- `booking-service` on port `3002`
- `notification-service` on port `3003`
- `user-db` PostgreSQL
- `event-db` PostgreSQL
- `booking-db` PostgreSQL
- `redis`
- `kafka` in single-node KRaft mode

## Value Files

- `values.yaml` contains the default chart configuration.
- `values-dev.yaml`, `values-staging.yaml`, and `values-prod.yaml` are the environment overlays used by `scripts/deploy.sh`.
- `values-minikube.yaml` switches application images to local Minikube tags and lowers resource requests.

## Database Migrations

Each application deployment runs its Prisma migration step in an initContainer before the main app container starts.

- User Service migrates `user-db`
- Event Service migrates `event-db`
- Booking Service migrates `booking-db`

That keeps fresh installs reproducible without relying on pre-existing tables or a seeded volume.

## Minikube Images

The Minikube workflow builds these local images into the Minikube Docker daemon:

- `event-booking/user-service:local`
- `event-booking/event-service:local`
- `event-booking/booking-service:local`
- `event-booking/notification-service:local`

`values-minikube.yaml` sets `imagePullPolicy: Never` for those images so Kubernetes does not try to pull them from a registry.

## Install

```bash
./scripts/deploy.sh helm dev
```

For local Minikube development:

```bash
./scripts/minikube-start.sh
```

That helper starts Minikube if needed, builds the local service images, installs the chart with `values-minikube.yaml`, and opens port-forwards for the APIs.

## Inspect

```bash
helm list -n event-booking
kubectl get pods -n event-booking
kubectl get svc -n event-booking
kubectl get statefulsets -n event-booking
```

## Uninstall

```bash
helm uninstall event-booking -n event-booking
```

## Override Example

```bash
helm upgrade --install event-booking infrastructure/helm/event-booking \
  -f infrastructure/helm/event-booking/values-minikube.yaml \
  --set global.logLevel=debug \
  --set eventService.cacheTtlSeconds=300
```

## Notes

- User Service uses PostgreSQL, not SQLite.
- Database credentials and demo URLs are local-only placeholders for local development.
- Redis and Kafka are internal ClusterIP services addressed through Kubernetes DNS names generated by the chart.
